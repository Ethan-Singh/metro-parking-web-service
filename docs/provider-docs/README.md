# Provider documentation

Official API specifications, provider guides, and data-format references are
grouped here by provider product. Captured request/response samples and
downloaded production feeds belong in [`../apis/`](../apis/), organized by API
version and resource.

| Folder | Contents |
| --- | --- |
| [`car-park-api/`](car-park-api/) | Car Park API Swagger and v2.3 documentation |
| [`public-transport/trip-planner/`](public-transport/trip-planner/) | Trip Planner Swagger and technical manual |
| [`public-transport/timetables/complete-gtfs/`](public-transport/timetables/complete-gtfs/) | Complete GTFS Swagger and pathways documentation |
| [`public-transport/timetables/realtime-v2/`](public-transport/timetables/realtime-v2/) | Realtime-capable GTFS schedule Swagger |
| [`public-transport/realtime/alerts-v2/`](public-transport/realtime/alerts-v2/) | GTFS-Realtime alerts Swagger |
| [`public-transport/realtime/trip-updates-v2/`](public-transport/realtime/trip-updates-v2/) | GTFS-Realtime trip update Swagger and TfNSW protobuf extension |
| [`public-transport/realtime/vehicle-positions-v2/`](public-transport/realtime/vehicle-positions-v2/) | GTFS-Realtime vehicle positions Swagger |
| [`toll-calculator/`](toll-calculator/) | Toll Calculator Swagger and technical manual |

Provider specifications remain separate from response samples and downloaded
feeds, which are organized under `docs/apis/`.
